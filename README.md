# 📚 Narodnici - Дигитална образователна платформа по литература

![Project Status](https://img.shields.io/badge/status-completed-success)
![.NET Version](https://img.shields.io/badge/.NET-ASP.NET_Core_MVC-blue)
![Database](https://img.shields.io/badge/Database-SQL_Server-yellow)

Настоящият проект представлява цялостна образователна уеб платформа, разработена като дипломна работа. **Narodnici** обединява богатата база данни на класическите електронни библиотеки със специализираните инструменти за интерактивно оценяване, добавяйки слой на геймификация и социално-академична ангажираност.

Основната цел на системата е да подпомогне учениците в тяхната литературна подготовка (включително за ДЗИ / Матура), като им предостави структурирано съдържание на едно място – от оригинални текстове и анализи до тестове и проследяване на личния прогрес.

---

## ✨ Ключови функционалности

*   📖 **Интелигентна библиотека:** Търсене и филтриране на литературни произведения по автор, жанр, клас и предназначение (за матура).
*   🧠 **Комплексно съдържание:** Всяко произведение включва оригиналния текст, резюме, структурирани анализи и авторска биография.
*   ✅ **Интерактивни тестове:** Модул за проверка на знанията с автоматично оценяване и запазване на резултатите.
*   📈 **Проследяване на прогреса:** Визуални индикатори (Progress bars) за "Готовност за матура" и отбелязване на прочетени материали.
*   📅 **Персонален календар:** Интегриран плановик за организиране на учебни сесии, свързани с конкретни произведения.
*   🏆 **Геймификация:** Автоматизирана система за печелене на значки (Badges) на база потребителска активност.
*   💬 **Социална ангажираност:** Модерирани дискусии и коментари под всяко произведение.
*   🔒 **Висока сигурност:** Двуфакторна автентикация (2FA) с 6-цифрен код по имейл (OTP) при смяна на парола.

## 🛠️ Използвани технологии

Проектът е изграден на базата на съвременен монолитен технологичен стек, използващ архитектурния шаблон **MVC (Model-View-Controller)**.

**Бекенд (Сървърна част):**
*   C# & .NET 8 (ASP.NET Core MVC)
*   Entity Framework Core (за достъп и управление на релационната база данни чрез Code-First подход)
*   ASP.NET Core Identity (за управление на потребители, криптиране на пароли, роли и сигурност)

**Фронтенд (Клиентска част):**
*   HTML5 / CSS3 / JavaScript (Vanilla)
*   Razor Syntax (за динамично рендиране на изгледи)
*   Bootstrap 5 (за респонсивна грид система и UI компоненти)
*   CSS Variables (за динамична Тъмна/Светла тема)

**База данни:**
*   Microsoft SQL Server (LocalDB)

**Външни библиотеки и интеграции:**
*   FullCalendar.io (за визуализация на персоналния учебен график)
*   Lucide Icons (за модерна и лека иконография)
*   System.Net.Mail (за автоматизирани email известия и OTP кодове)

## 👥 Потребителски роли и права

Системата използва йерархичен модел на достъп (Role-Based Access Control):
1.  **Гост (Guest):** Може да разглежда библиотеката, да търси произведения и да чете биографии. За пълен достъп се изисква регистрация.
2.  **Ученик (Student):** Има достъп до пълните текстове, анализи, решаване на тестове, трупане на прогрес, печелене на значки и участие в дискусии.
3.  **Учител (Teacher):** Разполага с права за добавяне, редакция и изтриване на произведения, анализи и създаване на тестове. 
4.  **Администратор (Admin):** Пълен достъп до системата, включително управление на потребителските роли и модериране на всички секции.
